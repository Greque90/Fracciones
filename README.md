# AnalizaMat — Prototipo Streamlit

Aplicación para organizar y analizar didácticamente producciones escritas de estudiantes en actividades de Matemática, inicialmente centrada en fracciones.

## 1. Requisitos
- Python 3.10 o superior
- Conexión a Internet para instalar dependencias
- Opcional: clave de API de OpenAI para habilitar la lectura asistida de imágenes
